Hybrid retrieval, computed live in your browser.

github.com/Alistair77/ragstar

This is the retrieval half, running for real. Vector search, BM25, Reciprocal Rank Fusion, cross-encoder reranking and the refusal gate all execute in this tab — no server, no API keys. The scores below are computed now, not replayed.

Two steps need a multi-GB local LLM, which is not something to download into a web page, so they are skipped here: writing the final sentence, and rewriting your query first. That second one is visible — type PTO policy and it will refuse, because the documents say "paid time off" and nothing says "PTO". The full version expands the abbreviation before searching and finds it.

Verified against the Python pipeline: identical refusal decisions, and scores within ~0.1 (this page runs q8-quantised weights; the real one runs float32).
